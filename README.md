# IGBot

IGBot — Android-застосунок для керування автоматизацією Instagram. Інтерфейс написаний на Kotlin і Jetpack Compose, а логіка обробки акаунтів та черги — на Python, вбудованому в застосунок за допомогою Chaquopy.

## Можливості

- **Огляд:** запуск і зупинка основного воркера, стан черги, статистика оброблених і пропущених профілів, помилки та лічильники дій.
- **Збір аудиторії:** пошук профілів серед підписників заданого акаунта, лайкерів поста або публікацій за хештегом. Під час збору профілів застосовуються фільтри й паузи з налаштувань.
- **Черга:** імпорт готової черги профілів із JSON-файлу.
- **Ліміти та режим:** налаштування лайків і переглядів сторіс на годину та день, активного часу, правил обробки й пауз парсера.
- **Акаунти:** окремі акаунти для основного воркера та парсера, вхід через Instagram WebView і налаштування проксі.
- **Фоновий режим:** foreground service з постійним сповіщенням, збереженням параметрів активних задач і їх відновленням, якщо Android перезапустить службу.
- **Журнал подій:** перегляд стану й повідомлень Python-рушія.

## Стек

- Kotlin, Android Jetpack Compose, Material 3
- Python 3.12 через Chaquopy 17.1.0
- `requests` для Python
- SQLite для локальної черги та журналу лімітів
- Android Gradle Plugin 9.4.1, Gradle 9.6.0

## Вимоги для збирання

- Android Studio з Android SDK Platform 37 та відповідними Build Tools
- JDK 17 для Gradle/Android Gradle Plugin
- Python 3.12, доступний через PATH або заданий параметром Gradle
- Підключення до інтернету для Gradle та завантаження залежностей

Chaquopy автоматично шукає Python 3.12 у `PATH`. Якщо він встановлений нестандартно, задайте шлях без редагування файлів проєкту:

```powershell
.\gradlew.bat assembleDebug -PchaquopyPython="C:/Python312/python.exe"
```

Не комітьте локальні шляхи до інструментів у спільні зміни.

## Збирання

Відкрийте проєкт у Android Studio, дочекайтеся Gradle Sync і зберіть APK:

```powershell
.\gradlew.bat assembleDebug
```

Готовий debug APK буде створений у `app/build/outputs/apk/debug/`. Щоб встановити його на підключений Android-пристрій з увімкненим USB debugging:

```powershell
.\gradlew.bat installDebug
```

Також можна запустити застосунок на пристрої або емуляторі кнопкою **Run** в Android Studio.

## Запуск і перше налаштування

1. Встановіть застосунок на Android 8.0 (API 26) або новішу версію.
2. У вкладці **Акаунти** увійдіть окремо для основного воркера та парсера. Для стабільної роботи у фоні за потреби налаштуйте виключення з оптимізації батареї.
3. У вкладці **Ліміти** перевірте частоту дій, активний час та параметри збору.
4. У вкладці **Парсер** задайте джерело й ціль або імпортуйте JSON-чергу.
5. Запустіть потрібний процес і стежте за станом на **Огляді**, а за повідомленнями — у **Подіях**.

## Дані застосунку

Python-рушій зберігає локальні налаштування, базу черги SQLite та файли сесій у внутрішньому каталозі застосунку. Зокрема, там зберігаються дані автентифікації Instagram. Видалення даних застосунку може видалити ці локальні дані та вимагати повторного входу.

## Структура

```text
app/src/main/java/com/maks/igbot/   Android UI, WebView і фоновий сервіс
app/src/main/python/                Python-рушій, клієнт, черга та налаштування
app/src/main/res/                   Ресурси Android
```

## Примітки

- Проєкт взаємодіє зі стороннім сервісом Instagram через його веб-інтерфейс та запити. Зміни сервісу можуть порушити вхід або роботу функцій.
- Дотримуйтеся правил Instagram і законодавства, отримуйте згоду власників акаунтів, використовуйте помірні налаштування й контролюйте активність. Ліміти в застосунку не гарантують відсутність обмежень з боку платформи.
- Застосунок не є офіційним продуктом Instagram і не пов’язаний із Meta.
